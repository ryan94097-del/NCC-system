# 使用說明（USAGE）

## 一、給使用者：怎麼在公司電腦用

1. 拿到 **`NCC核對工具.html`** 這個檔案（放桌面即可）。
2. **雙擊**用 Edge 或 Chrome 開啟。
3. 輸入共用密碼（預設 **`ncc2026`**）→ 按「解鎖」。
4. 點「上傳認證清單」選你的 Excel（或先按「載入測試樣本」試玩）。
5. 左上選 **年份**（預設 2026）。想只抽查幾筆就勾「抽樣模式」。
6. 每一列會有 **MOMO / Yahoo / Google / 露天 / 酷澎 / 蝦皮** 六個搜尋按鈕，點開就是那個產品在該賣場的搜尋結果。
7. 看到商品後，在該列填：**狀態**（已上架/未上架/存疑）、**賣家**、**價格**、**備註**；截圖可**拖放圖片**到「截圖」欄，或點該欄後按 **Ctrl+V** 貼上。
8. 進度會**自動存在瀏覽器**，關掉再開不會不見。換電腦或備份用「💾 匯出進度」，之後「📂 匯入進度」還原。
9. 完成後：**📄 匯出HTML報告**（含截圖，適合存證/繳交）或 **📊 匯出Excel** / **📑 匯出CSV**。

> 分享給同事：把「`NCC核對工具.html` 檔案 + 密碼」一起給對方即可。沒密碼的人開檔也是空的。

### 注意
- 本工具**不會自動抓價格/截圖/判斷上架**（公司環境無法自動連外爬蟲）。這些是你點開連結後**人工**判斷、手動填入。
- 已排除 PChome。
- 截圖只會保留在 **HTML 報告**；CSV/Excel 只記「截圖數」。

## 二、換密碼 / 更新工具（用 builder.html，免 Python）

1. 雙擊開啟 **`builder.html`**。
2. 輸入新密碼 → 按「產生加密工具」→ 會下載一個新的 `NCC核對工具.html`。
3. 把新檔發給同事、附上新密碼即可。
（`builder.html` 已內建工具與 SheetJS，離線就能產生，不需要 Python 或網路。）

## 三、給開發者 / AI 代理：重新產生流程

- 工具原始碼：`src/app.js`（邏輯）、`src/app.html`（開發用載入器）、`src/xlsx.full.min.js`（SheetJS）。
- 產生 `builder.html`：`python scripts/make_builder.py`（讀 `src/app.js` + SheetJS，內嵌並包好加密器）。
- 產生加密版 `NCC核對工具.html`：開 `builder.html`（瀏覽器）→ 輸入密碼 → 下載。
- 測試樣本：`python scripts/gen_sample.py` → 產生 `sample/NCC_測試樣本.xlsx`（去識別化）。
- 加密規格：PBKDF2-HMAC-SHA256（200,000 次、32 bytes 金鑰）→ AES-GCM（12-byte IV，密文含 tag），與瀏覽器 WebCrypto 相容。
